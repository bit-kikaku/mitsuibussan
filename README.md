# 採用ツールポータル（仮） — 静的MVPプロトタイプ

採用ツール（採用サイト・動画・パンフレット・SNS用ショート動画など）を **価格・納期・実績を見ながら買い物感覚で頼める** ポータルサイト。コンセプトは「採用ツールの ZOZOTOWN」。

> 最終構築環境は **WordPress** を想定していますが、本リポジトリはまず方向性とMVP要件を素早く形にするための **静的（HTML/CSS/バニラJS）プロトタイプ** です。仕様書のフェーズ1（7月初旬公開想定）の主要ページを実装しています。
> 価格・納期・社名・実績・画像は **すべてサンプル（仮）** です。実データに差し替える前提です。

---

## クイックスタート

ビルド不要。簡易サーバーで開いてください（`?id=` 等のクエリ・相対パスが正しく動きます）。

```bash
python3 -m http.server 8000
# → http://localhost:8000/
```

## ページ構成（フェーズ1 / MVP）

| ページ | パス | 内容 |
|---|---|---|
| トップ | `index.html` | 価値訴求・信頼バンド・注目商品・3分見積もり導線・実績・先行案内 |
| 商品一覧（棚） | `products/index.html` | カード一覧＋**用途で絞り込み**＋並べ替え（人気/価格/納期） |
| 商品詳細 | `products/detail.html?id=recs` | 価格・納期・含まれる内容・プラン（松竹梅）・FAQ・CTA |
| 3分見積もり | `estimate/index.html` | 用途→規模→オプションの**ステップ式概算**＋メール取得 |
| 実績 | `works/index.html` | 実績一覧（商品と紐づけ）＋信頼の数値 |
| コラム | `column/index.html` | 機能のみ（記事0で公開可）＋公開予定テーマ |
| 会社情報 | `company/index.html` | 会社概要・強み |
| お問い合わせ | `contact/index.html` | 会社名/担当/メール/電話/用途/相談内容。資料請求も兼ねる |
| 先行案内（既存客） | `members/index.html` | 周知メールのリンク先。限定特典の告知 |

## ディレクトリ構成

```
/
├── index.html
├── products/   index.html（一覧） / detail.html（詳細・?id=）
├── estimate/   index.html（見積もりシミュレーター）
├── works/      index.html
├── column/     index.html
├── company/    index.html
├── contact/    index.html
├── members/    index.html
└── assets/
    ├── css/  reset.css / style.css
    ├── js/   main.js（共通）/ catalog.js（一覧）/ detail.js（詳細）/ estimate.js（見積もり）
    └── data/ products.js（★商品マスタ：カタログ・詳細・見積もりの単一ソース）
```

### データ駆動（WordPress移行を見据えた設計）
- `assets/data/products.js` の `window.PRODUCTS` が商品マスタ。**カタログ・詳細・見積もりが同じデータを参照**します。
- WordPress移行時は、この構造をそのまま **カスタム投稿タイプ `product` ＋ ACF** にマッピングできます（価格min/max・納期・用途・含まれる内容・FAQ・プラン）。
- 実績は `window.WORKS`（→ CPT `works`）、コラムは標準投稿を想定。

## 仕様書との対応（フェーズ1で実装したMVP）
- ✅ 商品棚UI（カード／用途絞り込み／並べ替え／価格・納期・サムネ必須表示）
- ✅ 商品詳細（価格・納期・含まれる内容・サンプル枠・FAQ・CTA・松竹梅プラン）
- ✅ 3分見積もりシミュレーター（ステップ式＋簡易計算＋メール取得）
- ✅ リード獲得（問い合わせフォーム／資料請求／過去客先行案内ページ）
- ✅ 実績（商品と紐づけ・数値表示）／コラム（機能のみ）
- ⛔ カート・決済・複合絞り込み・レコメンド・自動返信は **フェーズ2以降**（MVPでは作らない）
